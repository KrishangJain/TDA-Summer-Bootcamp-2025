# Final Project (Week 5)

Tasks assigned:

    For your final project, you will be building an end-to-end Face Unlock Application using deep learning (DL) techniques.
    Project Overview:
    Your task is to design a Face Unlock system that leverages deep learning models for facial detection and authentication. The system should enable new users to register their faces and subsequently authenticate themselves in real time using a webcam or image input.

    Core Requirements:
    Face Registration: Implement a process for new users to securely enroll their face information.
    Real-time Detection and Recognition: Use deep learning for precise face identification and authentication.
    Authentication Flow: Grant or deny access based on facial match results, displaying clear feedback to the user.
    Performance and Security: Document model selection, accuracy, and address any security or privacy concerns.
    Documentation: Provide a detailed report covering your methodology, dataset preparation, choice of architecture, experimental results, and potential real-world applications.
    Tech Stack Suggestions:
    Python
    Deep learning frameworks such as TensorFlow or PyTorch
    Minimal UI for user interaction (use Streamlit if not familiar with traditional frontend Dev)
